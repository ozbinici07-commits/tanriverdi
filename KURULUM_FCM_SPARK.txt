Mimari:
Müşteri siparişi -> Realtime Database -> Cloudflare Worker /notify -> FCM -> Yönetici PWA -> bildirim

Firebase Functions KULLANILMIYOR. Firebase projesi Spark'ta kalır.
FCM arka plan kodu mevcut PWA sw.js içine birleştirildi; ayrı firebase-messaging-sw.js kullanılmıyor.

Dosyalar:
- index.html: tek birleşik PWA; FCM modülünü ana sayfadan yükler ve yeni siparişte Worker'a çağrı yapar.
- sw.js: PWA cache + FCM onBackgroundMessage.
- push.js: yönetici cihazında Notification izni, FCM token ve Realtime Database token kaydı.
- push-sender-worker.js: Firebase Admin HTTP v1 ile FCM göndericisi.
- manifest.webmanifest / ikonlar.

ÖNEMLİ: push.js artık iframe/srcdoc içinden import edilmiyor; ana index.html tarafından yükleniyor. Böylece ./push.js ve Service Worker yolları doğru origin'den çözülür.

Worker için Cloudflare Secret değişkenleri:
FCM_SERVICE_ACCOUNT_EMAIL = Firebase servis hesabı e-postası
FCM_SERVICE_ACCOUNT_PRIVATE_KEY = Firebase JSON içindeki private_key değeri

Worker deploy edildikten sonra /notify adresini tarayıcı tarafına tanriverdi_push_sender_url localStorage anahtarıyla ver veya index.html'deki varsayılan URL alanına ekle.

Not: Worker URL'si henüz bilinmediği için v3 paketinde boş bırakılmıştır. Bu URL olmadan token kaydı yapılabilir ancak otomatik yeni sipariş push bildirimi gönderilemez.

iOS: Web Push için PWA'nın Ana Ekran'a eklenmesi ve iOS'un Web Push destekleyen sürümünde bildirim izninin kullanıcı etkileşimiyle verilmesi gerekir. Paket, yönetici sekmelerine Bildirimleri Aç düğmesi ekler.
